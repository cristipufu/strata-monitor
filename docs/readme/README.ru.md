<a id="menu-bar"></a>

## Строка меню

- **Три показания в одном элементе.** Кольцо, центральное значение и полоса. Выберите, что каждый из них отображает в настройках, и сохраните комбинации как профили.
- **Наведите указатель мыши, чтобы развернуть.** Элемент открывается в отдельные чтения, а рядом с ним появляются элементы строки меню слева от него, скрытые до этого момента. Доступ к специальным возможностям или записи экрана не требуется.
- **Moments.** В этом элементе кратко показано, что только что изменилось: питание подключено или работает от батареи, низкий заряд батареи, новый вывод звука, отключение звука, подключение или удаление диска, отключение или восстановление сети, подключение устройства Bluetooth или процесс, остающийся тяжелым в течение нескольких минут. Необязательный.

## Панель

Щелкните элемент, чтобы открыть одну вкладку для каждой области. Каждая вкладка имеет один и тот же макет, сверху вниз: уведомления, текущее значение и его последняя минута, процессы, которые используются чаще всего, разбивка, последний час или день, затем списки и элементы управления на вкладке.

| Вкладка | Шоу |
|---|---|
| **Обзор** | Статус Mac (CPU, Память, Температура, Диск, GPU, Питание), живые плитки, самые загруженные процессы |
| **CPU** | Общая нагрузка, самые загруженные процессы, нагрузка на ядро, тепловое давление, история |
| **GPU** | Загрузка GPU, рендеринг и геометрия, память GPU, процессы с использованием GPU, история |
| **Память** | Используется и давление, крупнейшие процессы, активные, проводные, сжатые, кэш, подкачка, история |
| **Диск** | Свободное пространство, процессы записи больше всего, скорость чтения и записи, объемы |
| **Сеть** | Загрузка и выгрузка, процессы с использованием сети, интерфейсы, поиск портов, история |
| **Батарея** | Заряд и оставшееся время, мощность процесса, источник питания, здоровье, что не дает Mac спать |
| **Wi-Fi** | Сеть и сигнал, вкл/выкл, ближайшие сети |
| **Bluetooth** | Сопряженные устройства, подключение/отключение, дополнительные аккумуляторы |
| **Звук** | Громкость, отключение звука, выход |
| **Дисплеи** | Предварительный просмотр режимов, разрешения и зеркального отображения с 15-секундной отменой, Keep Awake |

**Просмотреть все** на любой вкладке открывает Проводник, отсортированный по размеру этой вкладки. Значения, которые еще не измерены, отображаются как «—», значения, которые macOS не предоставляет, отображаются как «Недоступно», а оценки отмечены как ≈.

<a id="explorer"></a>

## Исследователь

Каждый процесс на Mac, включая процессы других пользователей и системы, а также порты и открытые файлы.

- **Процессы или семейства**: плоский список или дерево процессов с итоговыми значениями для каждого семейства.
- **Ищите ** по имени, `pid:123`, `uid:501`, `user:root` или `port:3000`. **Show** фильтрует ваши процессы, других пользователей, систему, приложения, активные или приостановленные.
- **Columns** для времени CPU, потоков, питания, пробуждения, диска, GPU, состояния, типа и времени запуска.
- **Inspector** с недавней историей, мощностью, GPU, подписью, аргументами и библиотеками. Интерпретаторы и инструменты сборки показывают свой проект, например `bun · api`.
- **Actions**: пауза и возобновление, выход, завершение и принудительное завершение (подтверждено), выборка в течение 3 секунд, остановка процесса с удержанием порта, экспорт JSON. Сочетания клавиш в меню **Process**.
- **Временная шкала** устойчивого CPU, мощности, роста памяти и пробуждения из истории.

По умолчанию история сохраняется на Mac в течение 24 часов (Выключено, 24 часа или 7 дней в меню «Настройки» ▸ «Конфиденциальность») и сохраняет только показания и имена процессов, но не пути или аргументы.

<a id="system-processes"></a>

## Системные процессы

macOS предоставляет приложению точные показания только для процессов своего пользователя. Без посторонней помощи Strata Monitor показывает CPU других процессов и память из `ps` Apple (с маркировкой ≈).

**Show Exact Readings** добавляет дополнительный помощник для остального:

- Один клик при отсутствии показаний, одно одобрение администратором в настройках системы.
- Только чтение: без содержимого файла, аргументов, среды, сигналов, других инструментов или операций записи.
- Отвечает только Strata Monitor, подписанный той же командой, полные показания выдает только администраторам и завершает работу после 30 секунд простоя. Отключите его в «Настройки» ▸ «Конфиденциальность».

<a id="privacy"></a>

## Конфиденциальность

- Никакой учетной записи, отслеживания, аналитики или захвата пакетов.
- Только общедоступные интерфейсы macOS.
- История остается на Mac.
- При проверке обновлений свяжитесь с GitHub, если вы проверяете вручную или разрешаете автоматические проверки. Показания системы не отправляются.
- Местоположение (имена Wi-Fi) и доступ к Bluetooth запрашиваются только из их вкладок.

<a id="install"></a>

## Установить

Загрузите [последнюю версию](https://github.com/cristipufu/strata-monitor/releases/latest) и переместите Strata Monitor в Приложения. Требуется Mac с чипом Apple с macOS 26. Релизы подписываются и проходят проверку Apple.

Сборка из исходного кода с помощью Xcode 26 или Swift 6.2:

```sh
git clone https://github.com/cristipufu/strata-monitor.git
cd strata-monitor
scripts/build.sh release
open "build/Strata Monitor.app"
```

<a id="updates-and-languages"></a>

## Обновления и языки

Используйте **Проверить наличие обновлений… ** в меню Strata Monitor или включите ежедневные проверки и автоматическую установку в **Настройки ▸ Общие ▸ Обновления**. Обновления и лента обновлений подписаны. Автоматическая установка происходит при выходе из приложения.

Приложение поддерживает 22 языка. Выберите один из **Настройки ▸ Общие ▸ Язык**, затем закройте и снова откройте приложение или используйте язык, выбранный в macOS. Этот файл README доступен на английском, японском, корейском, русском, украинском, упрощенном и традиционном китайском языках.

<a id="development"></a>

## Разработка

```sh
scripts/test.sh            # all tests, with coverage
scripts/build.sh debug     # debug build in build/
scripts/benchmark.sh       # collection timings in build/benchmark.json
```

| Флаг запуска | Открывается |
|---|---|
| `--preview` | Исследователь (`--preview-self`, `--preview-families`) |
| `--preview-page <tab>` | Панель на одной вкладке |
| `--preview-strip` | Развернутый элемент строки меню |
| `--demo` | При любом предварительном просмотре: вымышленные данные вместо данных этого Mac |
| `--appearance light\|dark` | При любом предварительном просмотре: фиксированный внешний вид |
| `--render-glyphs <file.png>` | Записывает исследование пункта строки меню. |
| `--render-unfold <file.gif>` | Записывает анимацию разворачивания строки меню. |
| `--render-moments <file.gif>` | Пишет анимацию моментов |

Предварительный просмотр никогда не меняет ваши настройки. Архитектуру см. в [docs/IMPLEMENTATION.md](../../docs/IMPLEMENTATION.md).
